# Спецификация MVP

## Цель

Помочь пользователю выбрать однодневный пеший маршрут вокруг Гренобля по текстовому запросу, показав исходные характеристики маршрута, прогноз и ограничения рекомендации.

## Сценарий

1. Пользователь вводит запрос на русском языке и дату.
2. Локальная LLM извлекает предел времени, желаемый набор высоты, максимальную сложность и требование озера. Явно названные признаки выделяются ограниченным словарём в коде.
3. Backend вызывает инструменты MCP `search_routes` и `get_weather`.
4. Код проверяет, какие кандидаты точно соответствуют ограничениям.
5. Код считает балл соответствия 0–100, LLM выбирает маршруты на основе возвращённых данных и баллов; порядок задаётся баллом.
6. Backend пропускает только известные идентификаторы, формирует проверяемое объяснение из полей каталога и показывает результат со ссылками на источники.

## Границы

- География: каталог вокруг Гренобля; произвольные города пока не поддерживаются.
- Маршруты: проверенные записи Grenoble Alpes Tourisme, а не поиск по всему интернету.
- Погода: прогноз Open-Meteo у точки старта, до 16 дней; это не прогноз условий по всей тропе.
- Длительность, набор высоты и сложность: значения источника, без расчёта времени по геометрии. Желаемый набор высоты — критерий близости, не жёсткий предел.
- Изображение: для маршрутов через Лютель реальное фото озера с открытой лицензией и атрибуцией; на остальных карточках — подписанная декоративная иллюстрация.
- Проект не заменяет актуальные сведения о состоянии тропы, снеге и правилах посещения.

## Критерии приёмки

- Публичный URL открывает сайт без установки локальных программ.
- Запрос «рядом с Греноблем на 4 часа, с озером, не слишком сложный» проходит через две стадии LLM и оба инструмента MCP.
- Ответ содержит только маршруты из каталога и ссылки на их исходные страницы.
- Если точных совпадений нет, система сообщает об этом и указывает отличия альтернатив.
- При недоступной погоде маршрут может быть показан, но прогноз помечается недоступным.
- Дата вне горизонта прогноза не превращается в вымышленный прогноз.
- README содержит команды запуска и развёртывания, схему MCP и результаты проверки.
